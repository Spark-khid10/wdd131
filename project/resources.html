Resources

Free, genuinely useful resources, sorted by topic instead of dumped in one long list. These are the ones I actually use.

HTML & CSS

  • MDN Web Docs: Learn web development — the most reliable reference for how HTML and CSS actually work.
  • freeCodeCamp: Responsive Web Design — a free, structured course with built-in exercises.
  • CSS-Tricks — short, practical articles for when you're stuck on one specific thing.

JavaScript

  • javascript.info — thorough, modern, and free from start to finish.
  • Eloquent JavaScript — a full free book, good once you want to go deeper than tutorials.
  • MDN JavaScript Guide — the reference you'll keep coming back to.

Tools & Workflow

  • Git Documentation — the official docs, better than most tutorials once you know the basics.
  • GitHub Docs — for everything beyond just `git push`.
  • VS Code Docs — worth ten minutes to learn the shortcuts you'll use daily.

Community & Career

  • freeCodeCamp Forum — patient, beginner-friendly help.
  • DEV Community — articles and discussion from working developers.
  • r/learnprogramming — good for "is this normal?" questions.
