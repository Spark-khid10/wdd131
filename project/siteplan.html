Website Planning Document

Site Name

DevPath

DevPath was chosen because the site's purpose is to give beginners a clear path through learning software development — the name signals direction and progress rather than just another pile of tutorials.

Site Purpose

DevPath provides new programmers with a structured starting point for learning software development — a clear learning roadmap, curated free resources organized by topic, a list of common beginner mistakes to avoid, and an interactive tool that recommends where to start based on the visitor's goals and available time.

Scenarios

  • "I want to learn to code but have no idea where to start — what should I learn first?"
  • "Are there any free resources you'd actually recommend, instead of a huge unsorted list?"
  • "What mistakes do beginners usually make that I should try to avoid?"

Color Schema

DevPath uses a dark, code-editor-inspired palette: a deep purple background keeps the focus on content, while a single bright green accent is reserved for anything interactive, so it stays meaningful instead of noisy.

  • #1a1025 — Deep Purple — page background
  • #2e2147 — Lighter Purple — card and section backgrounds, borders
  • #4ade80 — Bright Green — headings, links, buttons, accents
  • #f1edf9 — Soft Lavender-White — body text

Typography

Two fonts are used: a monospace font for headings, nodding to the code-editor feel, and a clean sans-serif for body text so long passages stay easy to read.

  • Space Mono — used for all headings
  • Inter — used for body text, lists, and navigation

Wireframes

Simple block layouts for the DevPath home page, showing content placement rather than final content.
