The Roadmap

This is the order that actually works — not everything at once, not the fanciest framework first. Each stage builds on the one before it. Time estimates assume a few focused hours most days, not a full-time schedule.

  1. 1. HTML & CSS Fundamentals 2–4 weeks

    Before anything else, learn to structure a page and style it. This is the foundation everything else sits on — skipping it to jump into a framework almost always backfires later.

  2. 2. JavaScript Basics 4–6 weeks

    Variables, functions, loops, arrays, and the DOM. This is where a static page starts responding to the person using it — the first stage that feels like "real" programming.

  3. 3. Version Control with Git & GitHub 1 week, then ongoing

    Learn this early and use it from day one, even on tiny practice projects. It's much easier to build the habit now than to retrofit it onto months of untracked work later.

  4. 4. Build Three Small Projects 3–4 weeks

    Not tutorials — projects you design yourself, even if small. A to-do list, a calculator, a simple game. This is where HTML, CSS, and JavaScript actually click together.

  5. 5. Pick a Specialization 4–8 weeks

    Frontend (a framework like React), backend (a language like Node or Python plus a database), or mobile. Pick one direction and go deeper — trying to learn all three at once is the single biggest cause of beginner burnout.

  6. 6. Apply It Ongoing

    Contribute to an open-source project, build something for a real person, or apply for junior roles. Skills solidify under real constraints in a way practice alone can't replicate.
